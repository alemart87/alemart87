### Qué hago

Diseño y construyo productos con IA de punta a punta: desde la investigación del problema hasta el sistema en producción.
Me enfoco en herramientas que resuelven trabajo real de operaciones —contact center, cobranzas, ventas, selección y capacitación de personal— y en agentes de IA que se integran a los sistemas existentes.

- **Plataformas operativas** — backends FastAPI + frontends Next.js con autenticación JWT, perfiles y permisos configurables, auditoría y despliegue en un solo contenedor Docker.
- **Agentes y asistentes de IA** — RAG, agentes con herramientas, simuladores de clientes para entrenamiento y evaluación predictiva de desempeño.
- **Speech & conversation analytics** — procesamiento y análisis de llamadas para calidad y gestión.
- **SaaS propio** — [Chatia](https://www.chatia.pro): plataforma para crear agentes de IA para freelancers y pymes, con API REST pública y webhooks firmados con HMAC.

### Cómo trabajo

- **Seguridad primero:** secretos solo por variables de entorno, superadmin fuera de la base de datos, límites contra fuerza bruta, auditoría de acciones.
- **Entrega continua:** cambios chicos vía pull requests, tests de humo en la API y despliegue reproducible con Docker.
- **Producto antes que tecnología:** cada sistema empieza por el proceso operativo que tiene que mejorar y la métrica que lo demuestra.
